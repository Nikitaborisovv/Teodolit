# CLAUDE.md

## Проект

CMR-агент: заполняет международную накладную CMR в бланке пользователя по Commercial Invoice
и Packing List. Пользователь один (друг заказчика), продавать не планируется.
Текущее решение: «навык» для Claude (инструкции + справочник + бланки + скрипт заполнения),
а не отдельное приложение.

## Где что лежит

- `docs/research/cmr-countries.md` — правила CMR по странам (Китай, Турция, ОАЭ, Казахстан,
  Россия, Узбекистан), графы, бланки, тонкости. **Читать перед любой работой с CMR.**
- `samples/demo-01`, `samples/demo-02` — демо-комплекты на вымышленных данных с ожидаемыми
  значениями граф (README в каждой папке). Это тесты для агента.
- `tools/make_demo_docs.py` — генерация инвойсов и упаковочных листов из `data.json`.
- `tools/fill_cmr.py` — заполнение Word-бланка по карте полей `cmr-fields.json`.

## Правила

- Реальные документы заказчика (инвойсы, CMR, реквизиты, счета) **не класть в репозиторий**.
  Только вымышленные данные с пометкой SAMPLE.
- Buyer из инвойса ≠ Consignee в CMR. By order of — отдельный вопрос.
- Вес, места и список инвойсов считать кодом, не моделью.
- Подписи и печати не переносить.
- Отвечать пользователю по-русски, простыми словами; он часто читает с телефона.
