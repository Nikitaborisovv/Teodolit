# GLOSSARY

Bilingual reference. Use these exact terms in code and comments.

| Code term | English | Русский |
|---|---|---|
| `VV` | vertical axis (main) | вертикальная ось (главная) |
| `HH` | trunnion axis, telescope rotation axis | ось вращения трубы |
| `ZZ` | sight axis, line of sight, collimation axis | визирная ось |
| `HA` | horizontal angle, horizontal direction | горизонтальный угол / направление |
| `z` | zenith distance | зенитное расстояние |
| `v` | elevation, vertical angle | угол наклона / возвышения |
| `c` | collimation error | коллимационная ошибка |
| `i` | vertical index error, place of zenith (MZ) | место зенита (МЗ) |
| `face L` | circle left (КЛ) | круг лево |
| `face R` | circle right (КП) | круг право |
| alidade | rotating upper part | алидада |
| trunnion | telescope mount | подставка трубы |
| tilt | vertical-axis deviation from plumb | наклон вертикальной оси |

**Sight axis** = **line of sight** = **collimation axis**. Use `ZZ` or `sightAxis` in code.

**Place of zenith (MZ)** is the Russian term; international equivalent is **vertical index error**. Same quantity, denoted `i`.
